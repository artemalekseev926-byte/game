# Pixel Conquest

Пиксельная стратегия о захвате мира для ПК. Можно играть офлайн против ИИ и по сети с друзьями через **Steam** или по **локальной сети / IP**.

![icon](build/icon.png)

## Возможности

- **Пиксельная карта мира.** Сетка 240×96 построена по реальным очертаниям суши (Natural Earth) и разбита примерно на 220 провинций. Между ними проходят морские пути через проливы.
- **Встроенные карты:** Земля, Архипелаг, Пангея, Два континента, Внутреннее море и случайная карта по seed.
- **Пользовательские карты:** «Великий Крест» и «Шахматные острова» (лежат в `maps/`). Свою карту можно загрузить из JSON-файла.
- **Тёмная и светлая тема** (клавиша `T`), пиксельный шрифт, пиксельные спрайты и 8-битные звуки. Внешних ассетов нет: графика и звук генерируются кодом.
- **Войска:** пехота, танки и артиллерия. Артиллерия пробивает укрепления.
- **Постройки:** укрепления, фабрики, жилые дома, ПВО, аэродромы БПЛА и ракетные шахты (у каждой до 3 уровней).
- **БПЛА:** ударные дроны, дроны-камикадзе (разрушают постройки) и рой из 5 дронов, который перегружает ПВО.
- **Ракеты:** тактические, средней дальности и МБР с глобальной дальностью.
- **ПВО** перехватывает дроны и ракеты в своём радиусе. После каждого выстрела ей нужна перезарядка.
- **Девять веток исследований:** экономика, логистика, стрелковое оружие, бронетехника, артиллерия, фортификация, БПЛА, ракеты и системы ПВО.
- **ИИ трёх уровней сложности.** Он строит экономику, исследует, укрепляет границы, стягивает войска в ударные кулаки и бьёт дронами и ракетами.
- **Сохранения:** 3 слота и автосохранение каждую минуту (в одиночной игре).
- **Мультиплеер до 12 игроков:** Steam-лобби с приглашениями друзей или подключение по IP. Ботов можно добавлять и в сетевую игру. Если игрок отключился, его страной управляет ИИ. Есть чат.

## Экономика (переработанная)

- **Доход** складывается из налогов с населения и выпуска фабрик. Исследование «Экономика» даёт +10% за уровень.
- **Расходы.** Каждый юнит и каждая постройка (укрепления, ПВО, аэродромы, шахты) требуют содержания. В верхней панели показан чистый доход.
- **Перерасширение.** После 10 провинций эффективность управления плавно снижается, поэтому огромная империя не богатеет бесконечно.
- **Беспорядки.** Захваченная провинция 60 секунд платит половину налогов, теряет 30% населения, а её укрепления понижаются на уровень.
- **Удорожание построек.** Каждая следующая постройка того же типа стоит на 8% дороже, поэтому спамить фабриками не выгодно.
- **Долги.** Если казна уходит в минус, войска начинают дезертировать.
- **Людские резервы** растут вместе с населением. Жилые дома увеличивают лимит населения и скорость его роста.

## Скачать

Готовый файл для Windows — `PixelConquest-<версия>-portable.exe` в разделе **Releases** репозитория. Установка не нужна: скачайте и запустите.

## Запуск из исходников

Нужен [Node.js](https://nodejs.org) 18 или новее.

```bash
npm install
npm start          # собрать и запустить версию для ПК (Electron): офлайн, Steam, LAN
```

Есть и упрощённый вариант без установки: откройте `web/index.html` в браузере. Так доступна одиночная игра. Сетевая игра работает только в версии для ПК.

### Сборка .exe для Windows

```bash
npm run dist       # готовый release/PixelConquest-<версия>-portable.exe
```

Сборку можно запустить и на GitHub: при отправке тега `v*` (например, `v1.0.0`) GitHub Actions соберёт `.exe` на Windows и прикрепит его к релизу.

## Мультиплеер через Steam

1. Steam должен быть запущен у всех игроков.
2. Хост открывает «Мультиплеер» → «Создать лобби». Друзей можно пригласить кнопкой «Пригласить друзей» (оверлей Steam, Shift+Tab) или передать им **ID лобби** (кнопка «Копировать ID»).
3. Друзья запускают игру и заходят по приглашению, по ID лобби или из списка «Открытые лобби».
4. Хост выбирает карту, добавляет ботов и нажимает «Начать».

Игра использует [steamworks.js](https://github.com/ceifa/steamworks.js): лобби Steam плюс P2P-сеть Steam с ретрансляцией через серверы Valve, поэтому порты пробрасывать не нужно.

**AppID.** Файл `steam_appid.txt` содержит `480` (Spacewar), тестовое приложение Valve. С ним мультиплеер через Steam работает сразу, если у игроков запущен Steam. В профиле Steam при этом будет написано «Spacewar», а кнопка «Присоединиться к игре» в списке друзей не запустит Pixel Conquest — используйте приглашение из игры, ID лобби или список лобби. Чтобы выпустить игру в Steam под своим названием:

1. Зарегистрируйтесь в [Steamworks](https://partner.steamgames.com/) (Steam Direct) и получите свой AppID.
2. Впишите AppID в `steam_appid.txt` (или задайте переменную окружения `STEAM_APP_ID`).
3. Соберите игру командой `npm run dist` и загрузите содержимое `release/win-unpacked` через SteamPipe.
4. В настройках приложения в Steamworks включите Rich Presence. Тогда кнопка «Присоединиться к игре» передаёт игре `+connect_lobby <id>`, и игра обрабатывает это автоматически.

## Игра по локальной сети / IP

Подходит для LAN, Radmin VPN, Hamachi или игры с пробросом порта:

- Хост: «Мультиплеер» → «Создать сервер» (порт по умолчанию 27420). Игра покажет адрес для подключения.
- Остальные вводят адрес `IP:порт` и нажимают «Подключиться».

## Управление

| Действие | Клавиши |
|---|---|
| Выбрать провинцию | ЛКМ |
| Отправить войска / атаковать | ПКМ по цели (или кнопка «Отправить войска») |
| Доля отправляемых войск | Z / X / C / B = 25 / 50 / 75 / 100% |
| Прокрутка карты | перетаскивание мышью, WASD, стрелки |
| Масштаб | колёсико мыши |
| Пауза / скорость | Пробел / 1, 2, 3 |
| Исследования | R |
| Зоны ПВО | V |
| Тема | T |
| К столице | Home |
| Чат (сетевая игра) | Enter |
| Отмена / меню | Esc |

Наведите курсор на чужую провинцию, когда выбрана своя: появится прогноз боя (атака против обороны).

## Свои карты

Карта задаётся JSON-файлом. `#` означает сушу, `.` означает воду. Все строки должны быть одинаковой длины (от 10 до 400 символов), строк не больше 250.

```json
{
  "name": "Моя карта",
  "area": 30,
  "seaRange": 7,
  "rows": [
    "..........",
    "..####....",
    ".######...",
    "..####..##",
    ".........."
  ]
}
```

- `area` — средний размер провинции в клетках.
- `seaRange` — максимальная длина морского пути.

Файлы можно положить в папку `maps/` рядом с игрой или загрузить в меню «Одиночная игра» → «Загрузить свою карту». Если части суши не соединены, игра сама проложит между ними морские пути.

## Разработка

```bash
npm test           # тесты ядра (экономика, бои, ракеты, ПВО, ИИ) и сетевой синхронизации
npm run watch      # пересборка клиента при изменениях
npm run web        # браузерная версия на http://localhost:8080
npm run worldmap   # пересоздать пиксельную карту мира из Natural Earth
npm run maps       # пересоздать примеры пользовательских карт
```

Структура:

```
src/core/       ядро: генерация карт, симуляция, баланс, ИИ (без DOM, тестируется в Node)
src/client/     рендер, интерфейс, звук, сессии, лобби, сетевые транспорты
src/data/       растровая карта мира
electron/       версия для ПК: окно, Steam (steamworks.js), LAN-сервер (ws)
web/            index.html, стили, шрифт, собранный game.js
maps/           примеры пользовательских карт
test/           автотесты
```

Сетевая модель: хост ведёт авторитетную симуляцию (4 тика в секунду) и рассылает снимки состояния, где передаются только изменившиеся провинции. Клиенты отправляют команды, хост их проверяет. Карту каждый клиент генерирует сам по тому же seed.
